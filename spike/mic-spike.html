Manual tests (NOT TESTED until a human does them)

NVDA: can the whole page be used without sight?
  1. Start NVDA, then launch this page. Tab through every button; each must be announced with its label.
  2. Press "Request microphone access" with Enter or Space. Confirm NVDA reads the status message.
  3. Press "Record for 5 seconds"; confirm NVDA announces start and stop. Check that the level meter is not read out.
  4. Press "Play back recording" and confirm it plays while NVDA stays responsive. Then answer the "I heard / did not hear" buttons.
Windows privacy switch OFF (microphone access blocked)
  1. Do this yourself: Settings, Privacy and security, Microphone, turn OFF "Let desktop apps access your microphone". Do not use scripts.
  2. Run with --policy=allow-audio, press "Request microphone access" and write down the exact error name and message.
  3. Turn the setting back ON afterwards.
No microphone available
  1. Disable the capture device in Device Manager, or unplug the USB microphone (do this yourself).
  2. Reload with --policy=allow-audio and press "Request microphone access". Expected name to record: NotFoundError.
  3. Re-enable the device afterwards.
Device busy (another app holds the microphone)
  1. Start an exclusive-mode recorder in another app, then press "Request microphone access". Write down the error name (often NotReadableError).
Packaged app (file:// in a built app)
  1. Requires a build with the output directory moved off Vite's dist folder, which needs project configuration. NOT run by this spike. The --origin=file mode here is only a close proxy.
